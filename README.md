# Examsphere - Online Exam Portal

Examsphere is a MERN stack-based Online Exam Portal that allows users to register, log in, explore subject-wise tests, and take online exams.

## Features

- User registration and login
- Subject-wise multiple-choice tests
- Multiple tests for different subjects
- Automatic evaluation and score calculation
- Admin dashboard
- Exam and question management
- Student results management

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- JavaScript
- HTML and CSS

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/SanikaKatkarDot/Examsphere.git
cd Examsphere
```

### 2. Start the backend

Open a terminal in your backend folder:

```bash
cd backend
npm install
npm run dev
```

### 3. Start the frontend

Open another terminal in your frontend folder and run:

```bash
npm install
npm start
```

Configure your environment variables and MongoDB connection before starting the backend.
